🛡️ LMS Guardian (standalone)

Install guide for every main browser, on computer and Android.دليل التثبيت لكل المتصفحات الأساسية، على الكمبيوتر والأندرويد.

What you getماذا ستحصل عليه

A small add-on for the Ain Shams Engineering Moodle (lms.eng.asu.edu.eg) and the SIS. It makes the LMS nicer to use and works only for you, in your own browser. No account, no token, no bot, nothing is sent anywhere, and it never changes or submits anything.

  • Themes: Dark, Dim, Cyberpunk, Synthwave, Matrix, Midnight, Auto.
  • Compact layout and phone fixes for the new Moodle.
  • Not-submitted badges: assignments and quizzes you have not handed in show the time left, right on the course page.
  • Deadlines panel for all your subjects.
  • Download all files of a subject as one zip.
  • GPA calculator with the college scale (A+ and A = 4.0, A- = 3.7 …), one long list, can fill itself from your SIS grades.

إضافة صغيرة لموقع LMS كلية الهندسة جامعة عين شمس (lms.eng.asu.edu.eg) والـ SIS. بتخلي الموقع أريح في الاستخدام وبتشتغل لحسابك أنت فقط وعلى متصفحك أنت. من غير حساب ولا توكن ولا بوت، ومفيش أي بيانات بتتبعت لأي مكان، ومبتغيّرش ولا بتسلّم أي حاجة على الموقع.

  • ثيمات: داكن، خافت، سايبربانك، سينثويف، ماتريكس، ميدنايت، تلقائي.
  • عرض مضغوط وإصلاحات للموبايل للـ Moodle الجديد.
  • علامة «لم يُسلَّم بعد»: التكليفات والكويزات اللي لسه ما سلمتهاش بيظهر جنبها الوقت المتبقي في صفحة المادة.
  • لوحة المواعيد النهائية لكل موادك.
  • تحميل كل ملفات المادة في ملف zip واحد.
  • حاسبة GPA بتقدير الكلية (A+ و A = 4.0، A- = 3.7 …) في قائمة طويلة واحدة، وتقدر تتملي لوحدها من درجات الـ SIS.

Computer: Chrome, Edge, Brave, Operaالكمبيوتر: Chrome وEdge وBrave وOpera

Google Chrome

⬇ Download lms-guardian-chromium.zip

  1. Unzip the file. You get a folder: keep it somewhere permanent (for example Documents\LMS-Guardian). Do not delete it, the browser reads the add-on from there.
  2. Open chrome://extensions in the address bar.
  3. Turn on Developer mode (switch at the top or side).
  4. Click Load unpacked and choose the unzipped folder (the one that contains manifest.json).
  5. Open the LMS and log in. A round 🛡️ button appears at the bottom right.

⬇ تحميل lms-guardian-chromium.zip

  1. فك الضغط عن الملف هيطلع فولدر: سيبه في مكان ثابت (مثلا Documents\LMS-Guardian). متمسحوش، المتصفح بيقرا الإضافة منه.
  2. افتح chrome://extensions في شريط العنوان.
  3. شغّل Developer mode (مفتاح فوق أو على الجنب).
  4. اضغط Load unpacked واختار الفولدر (اللي جواه manifest.json).
  5. افتح الـ LMS وسجّل دخول. هيظهر زرار 🛡️ دايري تحت على اليمين.

Computer: Firefox (permanent, userscript)الكمبيوتر: Firefox (دائم، سكريبت مستخدم)

  1. Install Violentmonkey (or Tampermonkey) from Firefox Add-ons (addons.mozilla.org).
  2. Open this link: https://raw.githubusercontent.com/OMAR6972/lms-guardian/main/standalone/dist/lms-guardian.user.js. Violentmonkey shows an install page: press Confirm installation.
  3. Open the LMS and log in. The 🛡️ button appears at the bottom right.

If the link only shows text, open Violentmonkey → + → Install from URL and paste the link.

  1. نزّل إضافة Violentmonkey (أو Tampermonkey) من إضافات Firefox (addons.mozilla.org).
  2. افتح اللينك ده: https://raw.githubusercontent.com/OMAR6972/lms-guardian/main/standalone/dist/lms-guardian.user.js. هتظهر صفحة تثبيت: اضغط Confirm installation.
  3. افتح الـ LMS وسجّل دخول. هيظهر زرار 🛡️ تحت على اليمين.

لو اللينك فتح كنص بس: افتح Violentmonkey ← + ← Install from URL والصق اللينك.

Computer: Firefox (temporary add-on)الكمبيوتر: Firefox (إضافة مؤقتة)

⬇ Download lms-guardian-firefox.zip

  1. Unzip it to a folder.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on… and choose manifest.json inside the folder.

Firefox removes temporary add-ons when it closes, so you must repeat this every time. For a permanent install use the userscript above.

⬇ تحميل lms-guardian-firefox.zip

  1. فك الضغط في فولدر.
  2. افتح about:debugging#/runtime/this-firefox.
  3. اضغط Load Temporary Add-on… واختار ملف manifest.json اللي جوه الفولدر.

Firefox بيمسح الإضافات المؤقتة لما تقفله، فهتكرر الخطوات كل مرة. للتثبيت الدائم استخدم سكريبت المستخدم اللي فوق.

Phone: Firefox on Androidالموبايل: Firefox على أندرويد

  1. Install Firefox from Google Play and open it.
  2. Menu (⋮) → Add-ons (or Extensions) → find Violentmonkey → + → Add. (If it is not listed, use Tampermonkey.)
  3. In Firefox open this link: https://raw.githubusercontent.com/OMAR6972/lms-guardian/main/standalone/dist/lms-guardian.user.js and press Confirm installation. If it only shows text, open Violentmonkey from the add-ons menu and use Install from URL.
  4. Open the LMS and log in. The 🛡️ button is at the bottom right; the page itself is already fixed for small screens.

Menu (⋮) → Desktop site is not needed. To use the GPA fill-in, also open your SIS profile page once in the same Firefox.

  1. نزّل Firefox من Google Play وافتحه.
  2. القايمة (⋮) ← Add-ons (أو Extensions) ← دوّر على Violentmonkey ← + ← Add. (لو مش موجودة استخدم Tampermonkey.)
  3. من Firefox افتح اللينك ده: https://raw.githubusercontent.com/OMAR6972/lms-guardian/main/standalone/dist/lms-guardian.user.js واضغط Confirm installation. لو فتح كنص بس افتح Violentmonkey من قايمة الإضافات واستخدم Install from URL.
  4. افتح الـ LMS وسجّل دخول. زرار 🛡️ تحت على اليمين، والصفحة نفسها متظبطة للشاشات الصغيرة.

مش لازم تفعّل «Desktop site». عشان ملء الـ GPA من الـ SIS افتح صفحة البروفايل بتاعتك في الـ SIS مرة واحدة في نفس الـ Firefox.

Phone: Chrome, Brave, Opera, Edge (Android) and iPhoneالموبايل: Chrome وBrave وOpera وEdge (أندرويد) والآيفون

These phone browsers do not let you install add-ons or userscript managers (as of November 2026), so there is nothing to install in them. The easy fix: install Firefox and follow the Firefox on Android steps, then use Firefox only for the LMS. On iPhone and iPad this is not supported.

متصفحات الموبايل دي مبتسمحش بتثبيت إضافات أو مدير سكريبتات (حسب معلوماتي لحد نوفمبر 2026)، فمفيش حاجة تتثبّت فيها. الحل السهل: نزّل Firefox واتبع خطوات Firefox على أندرويد، واستخدمه للـ LMS بس. على الآيفون والآيباد غير مدعوم.

Using itالاستخدام

  • 🛡️ button (bottom right on the LMS): Deadlines (what is not submitted yet), GPA, Settings (theme and layout).
  • Course page: badges like “Not submitted · 4h 59m left”, a strip with the next deadlines, and a Download all files (zip) button.
  • GPA: log in to the SIS and open your profile page once; your grades are saved in this browser and the Fill from my SIS button fills the list. This term's subjects come in empty so you can try grades. Type hours and a grade or a percentage; rows without a grade are ignored.
  • زرار 🛡️ (تحت يمين في الـ LMS): Deadlines (اللي لسه ما اتسلمش)، GPA، Settings (الثيم والعرض).
  • صفحة المادة: علامات زي «لم يُسلَّم · باقي 4h 59m»، وشريط بأقرب المواعيد، وزرار Download all files (zip).
  • GPA: سجّل دخول على الـ SIS وافتح صفحة البروفايل مرة؛ درجاتك بتتحفظ في المتصفح ده وزرار Fill from my SIS بيملا القايمة. مواد الترم الحالي بتيجي فاضية عشان تجرّب درجات. اكتب الساعات والتقدير أو النسبة؛ الصفوف من غير تقدير بتتتجاهل.

Updating, removing, privacyالتحديث والإزالة والخصوصية

  • Update (folder install): download the new zip, replace the files in the same folder, then press the reload ↻ icon on the add-on card. Your settings and GPA list stay.
  • Update (userscript): Violentmonkey checks by itself, or press its update button.
  • Remove: remove the add-on from the extensions page (this also deletes your saved settings and GPA list).
  • Privacy: everything is stored only in your browser. It only reads pages you already see, and it never types, submits or changes anything on Moodle or the SIS. It never touches your password.
  • Not working? Reload the LMS page; make sure you are logged in; on a course page the zip and badges only appear on /course/view.php pages.
  • التحديث (تثبيت فولدر): نزّل الـ zip الجديد، استبدل الملفات في نفس الفولدر، واضغط أيقونة التحديث ↻ على كارت الإضافة. إعداداتك وقايمة الـ GPA بتفضل.
  • التحديث (سكريبت المستخدم): Violentmonkey بيشيّك لوحده، أو اضغط زرار التحديث.
  • الإزالة: شيل الإضافة من صفحة الإضافات (ده كمان بيمسح إعداداتك وقايمة الـ GPA).
  • الخصوصية: كل حاجة بتتخزن في متصفحك بس. بتقرا الصفحات اللي إنت شايفها أصلا، ومبتكتبش ولا بتسلّم ولا بتغيّر أي حاجة في Moodle أو الـ SIS. ومبتلمسش الباسورد.
  • مش شغّالة؟ اعمل ريلود للـ LMS؛ اتأكد إنك مسجّل دخول؛ الـ zip والعلامات بيظهروا بس في صفحات المادة /course/view.php.
